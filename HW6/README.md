## 단계③답

일반 Linear Regression은 수량과 단가를 각각의 계수와 곱한 후 더하는 방식이기 때문에 실제 총액의 곱셈 관계를 정확하게 표현하지 못하여 R²가 0.862에 그쳤다.

반면 수량과 단가를 곱한 qp를 새로운 특성으로 추가하면 실제 총액 계산식을 반영할 수 있으므로 R²가 1.0으로 향상되었다.

## 단계⑤결정과 이유
max_depth는 8로 결정하였다. 교차검증 평균 R²는 0.992로, 깊이 12의 0.995와 비교했을 때 차이가 0.003에 불과하므로 복잡도가 낮은 깊이 8을 선택하였다.

Training R²와 Test R²의 차이가 작은 이유는 총액이 수량과 단가의 곱이라는 명확한 규칙에 따라 결정되기 때문이다.


## 단계⑦답

Linear Regression + qp 모델을 선택하였다. 수량 40개, 단가 200,000원을 입력했을 때 Linear Regression + qp는 8,000,000원, Decision Tree(depth 8)는 7,362,301원을 예측하였으며 실제 총액은 8,000,000원이었다.

따라서 실제 총액 계산식과 일치하는 Linear Regression + qp 모델이 더 적합하다고 판단하였다.
